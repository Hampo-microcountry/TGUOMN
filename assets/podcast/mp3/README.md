# TGUOMN podcast MP3 files

Put the two ElevenLabs-generated narration MP3s in this folder with these exact names:

- `voice-1.mp3` — narrator option 1
- `voice-2.mp3` — narrator option 2

The player at `/neural-briefing.html` loads these paths:
- `assets/podcast/mp3/voice-1.mp3`
- `assets/podcast/mp3/voice-2.mp3`

## Adding the audio
1. Generate and download each narration as an MP3.
2. Rename the files exactly as above.
3. Upload both MP3 files into this folder in the GitHub repository.
4. Wait for GitHub Pages to deploy, then test Play, Pause, Restart, and the seek bar.

The audio player uses real HTML audio playback; it does not use device text-to-speech. Until the MP3s are uploaded, the player will report that the audio file is missing.
